# 오늘의 발자국

매일 간 곳과 그날의 사진, 짧은 내용을 달력에 남기는 **개인용 포토·장소 달력 다이어리**입니다.
기록과 사진은 서버로 보내지 않고 **오직 쓰는 기기의 브라우저 IndexedDB**에만 저장됩니다.

- 라이브: https://bswjys.github.io/place-diary/
- 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가**로 설치하면 앱처럼 쓸 수 있습니다.

## 쓰는 법

1. 앱을 열면 **오늘**이 달력에 선택되어 있고, 달력 **바로 아래 카드**에 오늘의 기록이 보입니다.
2. 달력에서 다른 날짜를 누르면 선택이 옮겨 가고, 아래 카드도 그 날짜의 기록으로 바로 바뀝니다.
3. 기록이 없는 날은 아래 카드에 `아직 오늘의 발자국이 없어요` 안내와 함께 **바로 적는 입력칸**이 펼쳐집니다(바텀시트를 열 필요 없음).
4. **🏠 집** — 사진 없이 그날의 내용만 적고 저장합니다.
5. **📍 외출** — 장소(직접 입력) + 사진(카메라/앨범) + 내용을 남깁니다. 사진을 고르면 **자르기(크롭)** 창이 뜨고, 열자마자 **✨ 자동 맞춤**이 사진 속 영수증·카드 영역을 찾아 테두리를 맞춰 줍니다. 여러 장을 고르면 `1 / N` 순서로 한 장씩 `자르기 적용` 또는 `원본 그대로`로 넘깁니다.
6. 같은 날 `+ 기록 추가`나 `📍 외출`을 다시 눌러 여러 곳을 이어서 기록할 수 있고, 카드에서 바로 **수정·삭제**할 수 있습니다.
7. **시간(선택)** — 기록마다 시각을 남길 수 있습니다. 비워 두어도 저장되고, 남기면 카드 위에 `오전 11:30`처럼 보입니다. `지금`을 누르면 지금 시각이 들어갑니다.
8. **순서 바꾸기** — 하루에 기록이 2개 이상이면 카드 오른쪽 `↑` `↓`로 그날 안의 순서를 바로 바꿀 수 있습니다. 바꾼 순서는 기기에 저장되어 새로고침해도 그대로입니다. (맨 위 카드의 `↑`와 맨 아래 카드의 `↓`는 흐리게 표시됩니다)

## 달력 표시

| 표시 | 뜻 |
| --- | --- |
| `🏠` | 집에서 보낸 날 |
| `📍` | 외출했지만 사진이 없는 날 |
| 사진 썸네일 | 외출 사진이 있는 날 (그날 대표 사진) |
| `+N` | 그날 기록이 더 있다는 표시 |

## 기능

- 사진 자동 압축: 긴 변 1200px · JPEG 0.82, 달력용 정사각 썸네일 160px
- 사진 자르기(크롭): 자동 맞춤 · 비율 칩(자유·1:1·3:4·4:3) · ↺ 90° 회전 · 모서리/박스 드래그 · 최대 4장 1/N
- 여러 장(최대 4장) 첨부, 큰 화면 보기(라이트박스)
- 장소·내용 키워드 검색 → 결과를 누르면 그 날짜가 선택되고 아래 카드로 이동 (검색 결과에도 시각이 함께 보입니다)
- 기록별 시간(선택) 표시, 하루 안 순서 바꾸기(↑/↓) · 순서와 시각 모두 JSON 백업에 포함
- 장소 칸은 입력칸 하나만 (자주 가는 곳 칩·장소 편집 없음)
- JSON 백업/복원(사진 포함), 사용 용량 표시
- 오프라인 동작(PWA, `sw.js`)
